# 으뜸체력왕 기록 웹앱 아이콘·홈 화면 바로가기

화접중학교 2026 으뜸체력왕 선발대회 기록 웹앱(Google Apps Script)의 홈 화면 아이콘과 바로가기 페이지입니다.

- 바로가기: https://kimjs99.github.io/fitness-king-icon/ — 이 페이지에서 **홈 화면에 추가**하면 아이콘이 붙고, 누르면 기록 웹앱이 열립니다.
  Apps Script 웹앱은 구글이 감싼 페이지라 아이폰용 `apple-touch-icon`을 달 수 없어서 이 페이지가 대신 아이콘을 들고 웹앱으로 넘겨 줍니다.
  (그냥 열면 안내를 보여 주고 주소를 `?go=1`로 바꿔 둠 → 홈 화면에 저장된 주소나 웹 앱 모드로 열면 곧바로 웹앱으로 이동)
- 아이콘: `apple-touch-icon.png` 180px · `icon-192.png`(웹앱 탭 아이콘으로도 씀) · `icon-512.png` · `favicon-32.png`
- 원본 생성기: 비공개 저장소 `fitness-king-2026`의 `app/tools/icon.js`

아이콘·바로가기 외의 코드·자료는 없습니다.
